📅Año de lanzamiento

1993

Ian Murdock anunció el proyecto el 16 de agosto de 1993 y la primera versión de desarrollo apareció ese mismo año. Es una de las distribuciones más antiguas aún activas.

1996

Primera versión estable, Debian 1.1 «Buzz». Desde entonces cada versión lleva el nombre de un personaje de Toy Story.

🐧¿En qué está basada?

Debian no deriva de otra distribución: es una distribución madre (independiente) que usa el kernel Linux junto con las herramientas del proyecto GNU.

  • Versión estable actual: Debian 13 «Trixie» (agosto de 2025), con kernel Linux 6.12 LTS.
  • Soporta unas 9 arquitecturas oficiales, entre ellas amd64, arm64 y armhf.
  • Es la base de otras distros muy conocidas: Ubuntu, Linux Mint, Kali, Raspberry Pi OS, Tails…

⭐Características que la hacen distinta

Estabilidad extrema

Los paquetes se prueban durante meses antes de entrar en «stable». Ideal para servidores.

100 % software libre

Se rige por el Contrato Social y las Directrices de Software Libre de Debian (DFSG).

APT y paquetes .deb

Instalación y actualización sencillas con apt. Más de 60 000 paquetes disponibles.

Gobernanza democrática

El Líder del Proyecto se elige cada año por votación de sus desarrolladores.

Tres ramas

Stable (segura), Testing (próxima) y Unstable/Sid (lo más nuevo).

Soporte a largo plazo

Cada versión recibe ~3 años de soporte completo y se extiende hasta 5 con LTS.

👥¿Quién lo desarrolla?

Lo desarrolla el Proyecto Debian, una comunidad de miles de voluntarios repartidos por el mundo. No pertenece a ninguna empresa.

  • Fundador: Ian Murdock (1993); el nombre combina «Debra» y «Ian».
  • Dirección: un Líder del Proyecto (DPL) elegido cada año.
  • Respaldo legal y económico: la organización sin ánimo de lucro Software in the Public Interest (SPI), además de donaciones y patrocinadores.
